# SecureClassify Frontend

## Quick Start

1. Install dependencies:
```bash
cd frontend
npm install
```

2. Start development server:
```bash
npm run dev
```

3. Open browser: http://localhost:3000

## Features

- Login/Logout with JWT
- Dashboard with stats (CIA classification, trash count, activity)
- Data management (create, edit, delete with CIA scoring)
- Trash management (restore or permanently delete)
- User profile (update info, change password)
- Admin: Users, Departments, Categories, DataTypes, History management
